ATS Job Feed: Greenhouse, Lever, Ashby and Workable jobs in one schema

Give it a list of companies. It reads each company's public job board on Greenhouse, Lever, Ashby or Workable and returns one row per open job, with the same fields for every applicant tracking system (ATS): title, location, remote flag, salary where published, description and apply link.

No login, API key, browser or proxy is needed. It uses the job-board APIs the four vendors publish for careers pages.

Run the hosted feed on Apify Get the open-source library

Not affiliated with or endorsed by Greenhouse, Lever, Ashby or Workable.

Who it is for

  • Job boards and aggregators. Fill a niche board with the open roles of a list of target companies. A daily run adds the new jobs and tells you which ones have closed.
  • Recruiting and sales tools. Watch which companies are hiring, for which roles and where.
  • Market research. Track hiring by company, department, location or remote share over time.

The id stays the same from run to run, so a monitor only needs to remember the ids it has seen.

How it was checked

  • On 7 November 2026 it was run on 33 real company boards: 10 Greenhouse, 8 Lever, 9 Ashby and 6 Workable. For every board, the number of jobs returned equalled the number of postings in that ATS's own public API, and every job id was unique.
  • That run returned 3,204 jobs. Three full runs over the same boards took 14 to 35 seconds on one machine.
  • Only-new-jobs mode was checked on the same boards: the first run returned all 3,204 jobs and a second run straight after returned none.
  • The library has 42 automated tests that run against recorded responses from each ATS.

Limits

  • Only these four ATSs. Workday, SmartRecruiters, iCIMS, Taleo, SuccessFactors and Teamtailor are not supported, and neither are LinkedIn or Indeed.
  • It reads the companies you list. It does not search all jobs on the web by keyword.
  • A bare company name is a best guess and is flagged in the run report. A board link is exact.
  • Greenhouse boards hosted in its EU region are not covered. Lever EU boards need a jobs.eu.lever.co link.
  • The vendors can change or withdraw their public APIs at any time.
